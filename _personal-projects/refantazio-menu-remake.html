I am currently working on a Metaphor Refantazio UI recreation built in Unity. Below you can explore the various phases of development underwent for this project. More to come as this project matures.

Phase 1: Asset Pipeline Research & POC

Original
Recreation

Premise: Before committing to full production, I needed a reliable way to reproduce the game’s visual identity without relying on traditional artistic workflows. As a developer-first creator, the priority was establishing an asset pipeline that could consistently deliver high‑quality, game‑ready visuals with minimal manual illustration. The proof‑of‑concept above validated the following pipeline:

  • Source existing, game‑ready assets from spriters-resource.com .
  • Use GenAI tools such as Copilot to generate missing or derivative texture assets.

Conclusion: A hybrid pipeline, leveraging community‑ripped assets and targeted GenAI generation, provides a scalable, efficient path to achieving the final visual fidelity required for the project.

Phase 2: Menu and HUD Architecture

Architectural Priorities:

  • Ensure all transitions are deterministic, predictable, and fully debuggable.
  • Minimize cross‑system coupling by preventing UI components from referencing external systems, and vice versa.
  • Design a generic, extensible UI framework capable of supporting an open‑ended number of menu screens and HUD contexts.

Approach:

  • Implement a state‑machine–driven workflow for both menu navigation and HUD context management, paired with UniTask to maintain a fully asynchronous, main‑thread‑safe execution model.
  • Leverage C# events to eliminate downstream dependencies and use the Object Resolver pattern for upwards dependency injection, ensuring upward dependencies remain abstract and intentional.
  • Use inheritance to define a unified UI lifecycle without requiring the core system to know anything about individual menu pages or HUD contexts. This keeps the architecture scalable, future‑proof, and resistant to scope creep as production evolves.
